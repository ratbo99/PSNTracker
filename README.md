# PSNTracker
this is a small Node Tool to provide a Overlay for earned Playstation Trophies by cheking the Plastation Network API.

What you need:
- your Playstation PSN Name
- NPSSO Cookie

To get the NPSSO Cookie - open your browser and login in to Playstation Store (https://store.playstation.com/)
  open a new tab and go to https://store.playstation.com/
