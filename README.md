# PSNTracker
this is a small Node Tool to provide Textfiles and an Overlay for earned Playstation Trophies by cheking the Plastation Network API.

What you need:
- your Playstation PSN Name
- NPSSO Cookie

To get the NPSSO Cookie - open your browser and login in to your Playstation Account: https://my.playstation.com/
then goto https://ca.account.sony.com/api/v1/ssocookie an copy the NPSSO Key

Start PSNTracker type in the PSNId you want to track and the copied NPSSO Key.
